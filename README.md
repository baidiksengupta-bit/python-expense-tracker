# 📊 Personal Expense & Budget Tracker (Pure Python)

A desktop Graphical User Interface (GUI) application built using **100% standard Python** (`tkinter`, `csv`, `datetime`, `os`) with **zero external library dependencies**.

## ✨ Key Features
- **Add & Validate Expenses:** Categorize daily student expenses with automatic date stamping and input validation.
- **Persistent CSV Storage:** Saves all records automatically to `expenses.csv` (compatible with Microsoft Excel).
- **Live Category Filter & Deletion:** Filter history by category or remove entries in real time.
- **Built-in Visual Bar Chart:** Dynamically renders proportional horizontal percentage bars on a `tkinter.Canvas` without requiring `matplotlib`.

## 🚀 How to Run
1. Ensure **Python 3.x** is installed on your system.
2. Download `expense_tracker.py` and `expenses.csv` into the same folder.
3. Run the application:
   ```bash
   python expense_tracker.py
